# Plan de screenshots stores

Les captures de fiche doivent provenir de la vraie application ou d'un environnement de démonstration réaliste. Ne pas utiliser de faux écrans générés qui montreraient des fonctions inexistantes.

Jeu conseillé :

1. **Dashboard**
   - 2 cotisations réalistes ;
   - progression visible ;
   - aucune donnée personnelle réelle.

2. **Créer une cotisation**
   - titre, objectif, durée ;
   - forfait lisible ;
   - wording 0 % sur les contributions.

3. **Détail organisateur**
   - progression ;
   - contributions confirmées / en attente ;
   - actions principales.

4. **Page publique**
   - objectif ;
   - progression ;
   - contexte de la cotisation.

5. **Contribution**
   - formulaire ;
   - transfert direct ;
   - message de confirmation.

6. **Profil**
   - réception des contributions ;
   - confidentialité / support ;
   - suppression du compte.

Utiliser des noms fictifs et des numéros de démonstration. Ne jamais exposer de référence de paiement réelle, téléphone client, clé API, QR privé ou donnée de production.
