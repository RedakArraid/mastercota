## Description courte

Créez, partagez et suivez vos cotisations de groupe simplement.

## Description complète

Mastercota aide les groupes à organiser leurs cotisations sans listes dispersées, captures d'écran ni calculs manuels.

Créez une cotisation, fixez un objectif et une durée, puis partagez le lien dans votre groupe WhatsApp ou ailleurs. Les participants peuvent contribuer sans créer de compte Mastercota.

Avec Mastercota, l'organisateur peut :

- suivre la progression de la cotisation ;
- voir les contributions signalées ;
- vérifier puis confirmer les montants réellement reçus ;
- partager une page claire avec le groupe ;
- garder un historique de la collecte ;
- clôturer ou prolonger la cotisation selon les règles affichées.

Les contributions sont versées directement à l'organisateur via le mode de réception configuré. Mastercota ne conserve pas l'argent de la cotisation et prélève 0 % sur le montant des contributions.

L'organisateur paie uniquement le forfait Mastercota applicable à la durée de sa cotisation. La première cotisation peut être offerte selon les conditions affichées dans l'application.

Mastercota est conçu pour les mariages, l'entraide, les associations, les groupes d'anciens, les équipes et les communautés qui souhaitent un suivi simple et transparent.

## Notes pour la fiche

Ne pas mentionner PI-SPI ou Paystack dans la fiche publique : ce sont des rails techniques pour les frais Mastercota et l'administrateur contrôle le fournisseur actif.

Ne pas promettre de confirmation automatique des contributions Wave : le transfert est signalé par le participant puis vérifié par l'organisateur.
